### The footprint editor's held actions and the board's footprint doors

Island `v0.2.3-cc25`. KiCad's footprint editor and the board open windows of KiCad's own that the host's footprint editor page replaces, so the island holds them and the frame sends `ev.held { action }` in their place (from a key, and on an engine whose menus ask the page, `heldMenus`, from KiCad's menus and toolbars); `action.run` of one answers `held`. Each is held only in its frame, only while `ev.ready` listed the cap beside it and a document is open (in an `fpedit` frame: a footprint is open), one `ev.held` per press:

- `fpedit`, under `fpedit` (the footprint editor's own cap: every fpedit export present): `common.Control.save`, `common.Control.saveAs`, `common.Control.revert`, `common.Control.print`, `common.Control.quit`, `common.Interactive.find`, `common.Control.showDatasheet`, `common.Control.showProperties`, `common.Control.showLibraryTree`, `common.Control.show3DViewer`, `common.Control.showFootprintBrowser`, `common.Control.newLibrary`, `common.Control.addLibrary`, `pcbnew.ModuleEditor.newFootprint`, `.createFootprint`, `.editFootprint`, `.duplicateFootprint`, `.renameFootprint`, `.deleteFootprint`, `.cutFootprint`, `.copyFootprint`, `.pasteFootprint`, `.importFootprint`, `.exportFootprint`, `.footprintProperties`, `.padTable`, `.checkFootprint`, `.loadFootprintFromBoard`, `.saveFootprintToBoard`, `.repairFootprint`, `pcbnew.EditorControl.EditLibFpInFpEditor`, `pcbnew.Control.previousFootprint`, `.nextFootprint`, `pcbnew.PadTool.defaultPadProperties`, `.enumeratePads`, `.PushPadSettings`, `pcbnew.GlobalEdit.cleanupGraphics`, `.editTextAndGraphics`, `pcbnew.InteractiveDrawing.placeImportedGraphics`, `.placeReferenceImage` and `pcbnew.FpWizard.showWizards`. A pencil press of the last two drawing tools arrives as `ev.held` too: the host opens its own picture and drawing import there.
- `pcb`, under `footprintEdit` (`footprint.forEditor` and `footprint.push`): `pcbnew.EditorControl.EditFpInFpEditor` (Ctrl+E on a footprint), `pcbnew.EditorControl.EditLibFpInFpEditor` (Ctrl+Shift+E) and `common.Control.showFootprintEditor`. The host opens its own footprint editor on the selected footprint, or on none.

On an engine without the fpedit exports (before engine run 15) an `fpedit` frame lists no `fpedit` and holds none of these; a `pcb` frame without `footprintEdit` lets KiCad open its footprint editor as before. The doors table (`bridge/ext/contextMenuDoors.json`) names `pcbnew.ModuleEditor.padTable` and `pcbnew.PadTool.PushPadSettings` `held`.
