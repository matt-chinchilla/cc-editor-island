<!-- part: notes settings.set -->
- A dielectric sublayer added or removed (island `v0.2.3-cc25`, engine run 15): a `stackup` set's `value` may be exactly `{ addDielectric: { after } }` or `{ removeDielectric: { index, sub } }` in place of `{ rows }`, one per set, as Board Setup's Add Dielectric Layer and Remove Dielectric Layer work (KiCad's own `BOARD_STACKUP_ITEM` calls, the board thickness rebuilt from the stackup). `after` and `index` name a stackup item as the section's rows name it (an enabled dielectric), `sub` one of its sublayers, each an integer from 0 to 255; add puts a new sublayer after the item's last, its material KiCad's "Not specified"; remove takes a sublayer of an item that has two or more. `dryRun` checks the form and changes nothing. The answer is the `stackup` section read back, one row more or one row less. A host gates both on `ev.ready` `caps` listing `settings:stackupLayers`, listed in a `pcb` frame exactly when the engine's `kicadSettingsSections()` names `stackupLayers` in its board half.
- The checks of a dielectric form, in order: the form (`bad_args`: both keys, another key beside one, any other key or type inside); in a `pcb` frame with the engine up, `unsupported` naming `kicadSettingsSections` on an engine without that marker (run 14) or `stackupLayers` when the marker does not list it; then as for every set (the frame's kind, a board open, `busy`). The engine answers `bad_args` when the item is no enabled dielectric, the stackup holds 256 rows already, or the item to take a sublayer from holds one only. No undo step (KiCad never undoes a setting).

- With engine run 15 (island `v0.2.3-cc25`) `solder_mask_expansion` of a pad, shape or track carries its numbers from the board's mask constraint (`min`, `opt` and `max` as KiCad gives them, never all null), and the clearance of two pads of one through hole part names only the board's enabled copper layers (four on Glasgow), never the 32 copper layers a through hole pad's layer set holds.
