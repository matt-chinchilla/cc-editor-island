- `ev.tool { name: string }` (the island of engine build T17, the `activeTool` cap): the tool KiCad's top frame holds, its own name (`pcbnew.InteractiveRouter.SingleTrack`, `eeschema.InteractiveDrawingLineWireBus.drawWires`, ...; `common.InteractiveSelection.selectionTool` when no other tool is armed). Sent once right after `ev.ready` with the tool held then, and after that on each change, never twice in a row with the same name; a tool that runs another and returns to it sends no selection tool in between. Exactly these keys.

### Engine build T17's reads: library tables, action states, the tool KiCad holds, exact clarify (unit t17-i)

The island of engine build T17 (engine run 15, train 17), in every frame. Each is feature detected on the engine export it needs, so an island on an older engine (T16b and before) lists none of these caps and answers both ops `unsupported` naming the export.

- **`libs.problems`** (no args; the cap `libTableProblems`, the engine's `kicadLibraryTableProblems`): the library tables KiCad could not read at its last pass over them, each `{ path, kind, message }`: `path` the table file's path in the frame's file system (a project table under the project folder, or a global table), `kind` `symbol`, `footprint` or `designBlock`, `message` KiCad's own sentence (the parser's, for example "Syntax error at line 5, column 131"). `[]` when none. A table that loads at a later pass leaves the list. KiCad shows no warning window for such a table on this engine (it did at engine start before T17, and the frame was busy until it was answered). A read: answered during a check, with or without a document. `bad_args` for any args, `not_ready` before the engine is up, `island_error` for an answer of another shape.
- **`actions.state { actions }`** (the cap `actionStates`, the engine's `kicadActionStates`): whether each named KiCad action reads checked now, as KiCad's own menus and toolbars mark it (its registered check condition on the frame's selection), in the top frame. `states` holds one key per distinct name asked: `true` or `false`, or `null` for a name that is no action of this frame, an action that is no toggle (no check condition registered, or KiCad's default never-checked one: reading false there would be a mark that lies), or a check that threw. The frame first waits for the engine's apply queue (1 s at most), so an `action.run` sent just before has run: `busy` when the queue stays busy, or a load is parked. `bad_args` for args of another shape (exactly `{ actions }`, 1 to 256 names, each KiCad's dotted action name), `not_ready` before the engine is up or when the engine has no frame up or an open in flight, `island_error` for an answer of another shape. A read: answered during a check.
- **`ev.tool`** (the cap `activeTool`, the engine's `kicadHostToolChanges` and `kicadActiveTool`): above. The frame takes the engine's slot (`window.kicadHostTool.onChange`) before the engine boots and reads `kicadActiveTool()` right after `ev.ready`, so the first `ev.tool` names the tool held at `ev.ready`.
- **`menuClarify`** (a cap only, listed when the engine has `kicadActionStates`, a name only build T17 has): this engine marks `ev.contextMenu` `clarify` true ONLY for KiCad's clarify-selection list; every other menu (a right click on one item, the bus unfold menu, a drawing tool's menu) reads `clarify` false. On an older engine every parked menu read `clarify` true, so a host tells the list apart by its items there and drops that guard only under `menuClarify`.
