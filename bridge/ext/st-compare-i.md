### item.compare
A placed symbol or a footprint compared with its source, the item of the same name in the library its nickname names, loaded through the frame's own libraries (the hosted mirror, the design's tables): KiCad's own Compare Symbol with Library in a `sch` frame and Compare Footprint with Library in a `pcb` frame, with no KiCad window (island `v0.2.3-cc25`, on an engine with `kicadCompareWithSource`, engine run 15; a host gates it on `ev.ready` `caps` listing `compare`, listed by `sch` and `pcb` frames). The args are exactly `{ uuid }` or, in a `sch` frame, `{ uuid, sheetPath }` in `symbol.get`'s grammar (a lowercase uuid; a sheet path in `project.open`'s form, absent for the engine's own choice of path); in a `pcb` frame the uuid is a footprint's and no `sheetPath` is taken. The checks, in order, before any effect: the args (`bad_args`); the frame (`unsupported` "item.compare runs in a sch or pcb frame"); the engine (`not_ready`, `unsupported` naming `kicadCompareWithSource`); a document open (`not_ready`); a load parked, a popup or a dialog up, or an item hanging off the pointer (`busy`). A read: answered during a `sheet.check` or a `board.check`.

`status` is KiCad's own verdict, `same` or `differs`, or `noSource` when the library is absent from the tables or disabled, or holds no item of that name: a success answer, never an error (the host offers Keep a copy). `source` is the source's library id text (`Device:R`, `Resistor_SMD:R_0603_1608Metric`). `findings` lists at most 512 differences, one per line KiCad's comparison reports, each with its `code`, the item it concerns (`uuid`, lowercase, or null), a pin number (`pin`, else `""`) and a field or setting name (`field`, else `""`); they are kept whatever the status (a `same` footprint can carry `boardStackup` lines, which KiCad calls informational). `DiffCode` is one of `power`, `unitCount`, `graphicCount`, `graphic`, `pinExtra`, `pin`, `pinMissing`, `fieldExtra`, `field`, `fieldMissing`, `fpFilters`, `keywords`, `pinNameOffset`, `showPinNames`, `showPinNumbers`, `excludeSim`, `excludeBom`, `excludeBoard`, `excludePos` (a symbol's), and `pad` (the uuid the board's pad, `pin` its number), `padCount`, `shape` (the uuid the board copy's item), `attributes` (`field` `type`, `allowSolderMaskBridges` or `boardOnly`), `boardStackup`, `dnp`, `stackup`, `override` (`field` `clearance`, `solderMask`, `solderPaste`, `solderPasteRatio` or `zoneConnection`), `netTie`, `barcodeCount`, `barcode` (the uuid the board copy's), `ruleAreaCount`, `ruleArea` (a footprint's), with `text`, `model` and `other` reserved (KiCad compares no footprint text and no model). `not_found` (naming the uuid, and the sheet path when one was asked) when the document holds no such item or the placed symbol carries no copy of its own to compare; `island_error` for an engine answer of another shape.

KiCad's own Compare Footprint with Library (`pcbnew.InspectionTool.DiffFootprint`) is held in a `pcb` frame and Compare Symbol with Library (`eeschema.InspectionTool.diffSymbol`) in a `sch` frame, both under the cap `compare`: each sends `ev.held { action }` and opens no window (`tests/e2e/st/st-compare-i.spec.ts`).
