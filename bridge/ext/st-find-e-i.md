### find
KiCad's own Find over the LIVE document (unsaved edits included), in a `sch` or a `pcb` frame with a document open (island `v0.2.3-cc25`, on an engine with `kicadFind`, engine run 15; a host gates it on `ev.ready` `caps` listing `find`, listed by `sch` and `pcb` frames). The args are exactly `{ text, matchCase, wholeWord, wildcards, regex }` and ONE face object, the frame's: `sch` with its nine booleans (`refs` designators, `values`, `fields` other fields, `hidden` hidden fields too, `pins` pin names and numbers, `labels` labels and text, `nets` net names, `thisSheet` this sheet only, `selected` the selection only) or `pcb` with its five (`refs`, `values`, `texts` other text and zone names, `nets`, `markers`). `text` is 1 to 256 code points with no NUL. The options follow KiCad's find dialogs in order: a regular expression, then whole words, then wildcards, else plain text; `matchCase` applies to each. The checks, in order, before any effect: the args (`bad_args`, a face of the other frame included); the frame (`unsupported` "find runs in a sch or pcb frame"); the engine (`not_ready`, `unsupported` naming `kicadFind`); a document open (`not_ready`); a load parked, a popup or a dialog up, or an item hanging off the pointer (`busy`). A read: answered during a `sheet.check` or a `board.check`.

The answer lists at most 4,096 hits, `truncated` true past that. Each hit names its item (`uuid`, lowercase), the sheet path it was matched on (`""` on a board), its `kind`, the designator `ref` of its part when it has one, the `field` name (a pin's number for kind `pin`), the item's `text` (cut at 1,024 code points) and where the match lies in it (`start`, `length` in code points; a wildcard match or a net name lights the whole text). In a schematic a part itself is never a hit: its designator or value is kind `symbol` (`field` "Reference" or "Value"), other fields `field`, pins `pin` (or `net` when only the net name matched), labels and sheet pins `label` (or `net`), text and text boxes `text`; a designator is listed on every sheet path that holds it, any other item on its first path only. On a board: one hit per footprint (`footprint` for its designator or value, else `text` or `field`), the board's own text `text`, zone names `other`, markers `marker`, nets `net`. A regular expression KiCad cannot compile answers `bad_args` "find: the regular expression does not compile"; an engine answer of another shape is `island_error`.

KiCad's own Find (`common.Interactive.find`, Ctrl+F), Search panel (`common.Interactive.search`, Ctrl+G), Find Next (`common.Interactive.findNext`, F3) and Find Previous (`common.Interactive.findPrevious`, Shift+F3) are held in a `sch` and a `pcb` frame under the cap `find`; Find and Replace (`common.Interactive.findAndReplace`, Ctrl+Alt+F) and Replace and Find Next (`common.Interactive.replaceAndFindNext`) in a `sch` frame under the cap `replace`. Each sends `ev.held { action }` and opens no window (`tests/e2e/st/st-find-e-i.spec.ts`).

### find.replace
KiCad's own Find and Replace in a `sch` frame with a schematic open (island `v0.2.3-cc25`, on an engine with `kicadSchReplace` and `kicadCollabBusy`, engine run 15; a host gates it on `ev.ready` `caps` listing `replace`, listed by `sch` frames only). The args are exactly `{ find, with, targets }`: `find`'s own args with the `sch` face, the replacement (0 to 256 code points, no NUL), and `"all"` or 1 to 4,096 hits sent back as `find` answered them. The checks, in order: the args (`bad_args`); the frame (`unsupported` "a replace runs in a sch frame"); the engine (`not_ready`, `unsupported` naming the first missing export); a schematic open (`not_ready`); `busy` as for `find`, and during a check or an import.

The frame queues the run with a fresh `/tmp/cc-replace/<n>/` for its records, waits for the apply queue to empty and the run's record, and removes the folder whatever the answer. Every target is found again first with KiCad's own matching (a target matched by its `uuid`, `sheetPath`, `kind` and `field`; one that no longer matches is counted in `skipped`), each replaced through its item's own Replace (designators only when `find.sch.refs` is true), as ONE commit "Find and Replace": one undo step, and an `ev.edited` once the depth moved. `no_match` when nothing was replaced (nothing changed); `not_applied` when the engine refused the run or no record came within about 30 s; `island_error` for a record of another shape.
