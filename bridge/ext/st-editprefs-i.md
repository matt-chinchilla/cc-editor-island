### Editing preferences: the sections `schEditing`, `pcbEditing` and `mouse`

Island `v0.2.3-cc25`, on an engine of run 15 or later. `settings.get` and `settings.set` take three more sections, KiCad's own Preferences pages with no KiCad window: `schEditing` in a `sch` frame (the schematic editor's editing options), `pcbEditing` in a `pcb` frame (the board editor's editing options) and `mouse` in both (the mouse and touchpad page; one object in the engine, so a set in either frame changes both). The keys are KiCad's own dotted JSON paths, each value KiCad's kind: `schEditing` the switches `appearance.footprint_preview`, `system.never_show_rescue_dialog`, `autoplace_fields.enable`, `autoplace_fields.allow_rejustify`, `autoplace_fields.align_to_grid`, `input.drag_is_move`, `drawing.auto_start_wires`, `input.esc_clears_net_highlight`, `annotation.automatic`, `input.allow_unconstrained_pin_swaps` and the numbers `drawing.new_power_symbols`, `drawing.line_mode`, `editing.arc_edit_mode`, `drawing.default_repeat_offset_x`, `drawing.default_repeat_offset_y` (mils), `drawing.repeat_label_increment`; `pcbEditing` the switches `editing.flip_left_right`, `editing.esc_clears_net_highlight`, `editing.show_courtyard_collisions`, `editing.magnetic_graphics`, `editing.ctrl_click_highlight`, `editing.auto_fill_zones`, `editing.allow_free_pads`, `pcb_display.ratsnest_footprint`, `pcb_display.ratsnest_curved`, `pcb_display.show_page_borders` and the numbers `editing.magnetic_pads`, `editing.magnetic_tracks`, `editing.track_drag_action`, `editing.arc_edit_mode`, `editing.pcb_angle_snap_mode`, `editing.rotation_angle` (tenths of a degree), `pcb_display.ratsnest_thickness`; `mouse` the switches `input.center_on_zoom`, `input.auto_pan`, `input.zoom_acceleration`, `input.zoom_speed_auto`, `input.horizontal_pan`, `input.reverse_scroll_zoom`, `input.reverse_scroll_pan_h` and the numbers `input.mouse_left`, `input.mouse_middle`, `input.mouse_right`, `input.motion_pan_modifier`, `input.scroll_modifier_zoom`, `input.scroll_modifier_pan_h`, `input.scroll_modifier_pan_v`, `input.auto_pan_acceleration`, `input.zoom_speed`. A set's `value` names any of its section's keys; another key, or a value of the other kind, is `bad_args` before the engine is asked, and the engine answers `bad_args` for a number outside what KiCad's page offers. The sheet colors of KiCad's schematic page are left out (colors stay the host's).

These are app settings, not the design's: a set makes no undo step, marks nothing modified and writes no file, and runs the rest of KiCad's Preferences OK (the tools reset and the canvas redrawn). An engine boots with KiCad's defaults, so a host keeps its reader's choices itself and sends them again after each `ev.ready`. A host gates each section on `ev.ready` `caps`: `settings:schEditing` in a `sch` frame, `settings:pcbEditing` in a `pcb` frame and `settings:mouse` in both, each listed exactly when the engine's `kicadSettingsSections()` names the section in that frame's half (never on engine run 14).

KiCad's Preferences window (`common.SuiteControl.openPreferences`: its key `Ctrl+,`, and its menu item where `heldMenus` is listed) is held in `sch` and `pcb` frames under `heldKeys` while a document is open: the frame sends `ev.held { action }` and opens nothing, and the host opens its own editing preferences instead.
