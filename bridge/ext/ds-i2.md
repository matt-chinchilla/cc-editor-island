- `ev.dsedit { ask: "image", uuid: "", isNew: true }`: in a `ds` frame (island `v0.2.3-cc25`, cap `dseditHeld`), KiCad's Place Bitmaps was pressed with no picture armed: it places nothing and opens no window, and the host offers a picture (then `dsedit.image.arm`, and the next press places it). Sent once per request, after `ev.ready`, while a drawing sheet is open. KiCad asks once per press on the drawing, and once more at the tool's start when the tool was started by its key (as `key.press` starts it): a host treats an ask that comes while its own picker is already open as already answered.

### The drawing sheet editor: items, defaults, preview, append and pictures

Island `v0.2.3-cc25`, on an engine with the dsedit exports (engine run 15); a host gates every op on `ev.ready` `caps` listing `dsedit`, and `ev.dsedit` on `dseditHeld` (the engine's marker `kicadHostDsEdit` beside every dsedit export). Every op makes the checks of the `dsedit` ops above in their order (`unsupported` outside a `ds` frame, `bad_args`, `not_ready`, `unsupported` naming the first missing export, `busy`, `no_sheet`). A change is ONE undo step of KiCad's, then an `ev.edited`; its answer is the read back once the engine's apply queue is empty and the sheet shows every key it set, else `not_applied` after about 5 s. Lengths and positions are millimeters as the sheet stores them, angles degrees; uuids lower case 8-4-4-4-12; strings at most 1,024 characters unless named.

- **Records.** `DsItem` is one of, each with exactly its keys: common `{ kind, uuid, name, comment, pages ("all" | "page1only" | "notonpage1"), start: DsPoint, repeat, step: [incrx, incry] }`, `DsPoint` `{ x, y, corner ("rbcorner" | "rtcorner" | "lbcorner" | "ltcorner") }` measured from that corner of the page's margins; a `line` or `rect` adds `{ end: DsPoint, lineWidth (0: the sheet's default) }`; a `text` adds `{ text (at most 4,096, names such as ${TITLE} kept as typed), labelStep, font ("" KiCad's own), bold, italic, color ("" or #rrggbbaa), hJustify ("left" | "center" | "right"), vJustify ("top" | "center" | "bottom"), rotation, size: [w, h] (0: the default), maxLength, maxHeight (0: none), lineWidth }`; a `polygon` adds `{ rotation, lineWidth, outlines, points }` (its shape is read only); a `bitmap` adds `{ ppi, width, height }` (pixels). `DsDefaults` is `{ lineWidth, textSize: [w, h], textThickness, margins: { left, right, top, bottom } }`. `DsPreview` is `{ paper (KiCad's name: A5 to A0, A to E, GERBER, User, USLetter, USLegal, USLedger), portrait, width, height, title, date, revision, company, comments (exactly 9) }`: the page and title block the sheet is previewed on, never written into the sheet.
- **`dsedit.items.get`** answers the open sheet's items in KiCad's draw order; with `uuids` (1 to 4,096) only those (an id the sheet does not hold is left out), with `kinds` (1 to 5 of `line`, `rect`, `text`, `polygon`, `bitmap`) only those kinds.
- **`dsedit.items.set`** sets `set`, a non empty partial of one kind's editable keys (never `kind`, `uuid`, a polygon's `outlines` or `points`, a bitmap's `width` or `height`), on every item of `uuids` (1 to 512), in KiCad's properties pane order: `bad_args` when an id is not on the sheet or an item's kind lacks a key. Bounds, as KiCad's pane: positions and steps within 10,000; `repeat` 1 to 500; `lineWidth` 0 to 10; `labelStep` within 100,000; `rotation` within 360; `size` 0 to 100 each; `maxLength`, `maxHeight` 0 to 10,000; `ppi` 1 to 100,000; a `text` may hold line breaks, no other control character anywhere. A `font` named by its face is resolved by KiCad's font lookup, so the read back shows KiCad's face for it.
- **`dsedit.items.add`** adds 1 to 64 whole items: a `line` or `rect` (every key of its record), a `text` (every key), or a `bitmap`'s common keys with `ppi` and `png` (base64 of a PNG of at most 4 MiB, which KiCad's picture reader must take); each `uuid` the host makes, never one the sheet holds (`bad_args`). A polygon is never added (KiCad has no polygon tool; polygons arrive by `dsedit.append`).
- **`dsedit.items.remove`** takes the items of `uuids` (1 to 4,096) off the sheet with KiCad's own delete (`bad_args` when an id is not on the sheet; `not_applied` while KiCad is placing one of them) and answers `{ removed }`.
- **`dsedit.defaults.set`**: `lineWidth` 0 to 10, `textSize` 0.01 to 100 each, `textThickness` 0 to 5, `margins` whole, each 0 to 1,000.
- **`dsedit.preview.set`**: `paper` one of the names above; `width` and `height` together (25.4 to 3,048) and only for a `User` paper; `portrait` only for the other papers (the paper the set names, else the one shown: `bad_args` otherwise); the four texts; `comments` exactly nine. The drawing redraws on that page.
- **`dsedit.append { text }`** adds every item of another `kicad_wks` (or legacy `page_layout`) document to the open sheet, its setup taken too, as KiCad's Append Existing Drawing Sheet: KiCad's own parser reads it first (`unreadable` with KiCad's line, nothing changed); past 8 MiB `too_large`. The answer `{ added }` lists the new items' uuids (an id the sheet already holds is replaced by a fresh one) once the sheet holds every one.
- **`dsedit.image.arm { bytes, name }`** holds a PNG (at most 4 MiB: `too_large`; KiCad's picture reader must take it, else `not_applied`) for KiCad's next Place Bitmaps press, which puts it on the pointer with no file dialog and disarms (the press after that places it, ONE undo step; a tool started by its key takes the start as its first press); empty `bytes` disarm. With nothing armed the press sends `ev.dsedit` and places nothing.
