### The footprint editor: an fpedit frame and the fpedit ops

Island `v0.2.3-cc25`, on an engine with the fpedit exports (engine run 15); a host gates every op on `ev.ready` `caps` listing `fpedit`.

- **The frame.** `?frame=fpedit` boots KiCad's own footprint editor (`FOOTPRINT_EDIT_FRAME`, a frame of `pcbnew`), canvas only, with no library tree loaded and no picker warm up. An `fpedit` frame holds no document of the project's: every op that ships answers `unsupported` ("a footprint editor opens footprints, not documents") but `project.write`, `project.libs`, `lib.index`, `lib.item`, `lib.prefetch`, `key.press`, `keys.claim`, `chrome.show`, `view.fit`, `select` and `shutdown` (KiCad's footprint layers come from the footprint's own record, not `layers.*`). In every other frame each `fpedit` op answers `unsupported` ("a footprint edits in an fpedit frame"). Of the built in caps an `fpedit` frame's `ev.ready` lists only `heldKeys`, `hostKeys`, `write` and `projectLibs`, with `fpedit` (every export below present), the caps the other footprint editor units list there (`fpeditHeld`, `footprintConvert`, `importGraphics`) and the engine's export names; no other frame lists `fpedit`. `ev.edited` in an `fpedit` frame carries the footprint's undo depth (`kicadFpEditState().depth`) while a footprint is open (an open or a new starts the count again and sends none); `ev.selected` carries the footprint's selected items (`kicadFpEditSelection()`, `fpPaths` `[]`) while a footprint is open.
- **The checks**, in order, every one before any effect: the args (`bad_args`); the frame's kind (`unsupported`); the engine (`not_ready` before it is up; `unsupported` naming the first missing export of `kicadFpEditOpen`, `kicadFpEditNew`, `kicadFpEditState`, `kicadFpEditTake`, `kicadFpEditMarkSaved`, `kicadFpEditItemsGet`, `kicadFpEditItemsSet`, `kicadFpEditItemsAdd`, `kicadFpEditItemsRemove`, `kicadFpEditFootprintGet`, `kicadFpEditFootprintSet`, `kicadFpEditPadDefaultsGet`, `kicadFpEditPadDefaultsSet`, `kicadFpEditEnumerate`, `kicadFpEditSelection`, `kicadFpEditSelect`, `kicadFpEditCheck`, `kicadFpEditCleanup`, `kicadFpEditEmbed`, `kicadFpEditPlotSvg`, `kicadCollabBusy`); a load parked, a popup menu or a dialog up (`busy`, nothing changed); then `no_footprint` for every op but `fpedit.open`, `fpedit.new` and `fpedit.state` while no footprint is open. An open or a new answers once the engine's apply queue is empty and the state shows it, else `not_applied` after about 5 s.
  - `FpEditState`: exactly `{ token, open, name, lib, mode, modified, depth (the undo depth), padCount, type, padEditMode }`. `token` is the island's own for the last open (1 to 64 printable characters, `""` before any), which `fpedit.markSaved` names; `name` the footprint's name (`""` with none open); `lib` the nickname it opened under (`""` for none, never a row of KiCad's table); `mode` the door it came through (`library`, `placed` or `new`); `type` KiCad's footprint type (`smd`, `through_hole` or `unspecified`); `padEditMode` KiCad's pad edit mode (a custom pad taken apart into its shapes).
- **`fpedit.open`** opens one footprint from its text (`text`, one `(footprint ...)` document, which KiCad's own parser reads; no library is loaded and no row of KiCad's table is named): `name` 1 to 1,024 characters and `lib` 0 to 1,024, with no control character, the names it opens under; `mode` `library` (a footprint of the design's own set), `placed` (a placed part's copy, from `footprint.forEditor`: its text kept as the board sent it) or `new`; `discard` a boolean (`held_edits` when the open footprint holds changes and it is false, nothing changed). The footprint lands at the origin, its Reference and Value filled with KiCad's placeholders when empty (but `placed`), the undo list empty, unmodified, the view fitted. Past 8 MiB of text: `too_large`. `unreadable` ("fpedit.open: the text holds no footprint KiCad reads") when KiCad's parser reads no footprint from the text, nothing changed. The answer is the state once the engine shows the open, with a fresh token.
- **`fpedit.new`** is KiCad's new footprint with no library (the host keeps names unique): `name` and `lib` as above, `type` `smd`, `through_hole` or `unspecified`, `discard` as above; then as `fpedit.open`, `mode` `new`. `bad_args` "fpedit.new: KiCad refused the new footprint" when the engine refuses it.
- **`fpedit.state`** answers the state, a footprint open or not. **`fpedit.take`** answers the open footprint as library text by KiCad's own formatter, from a copy reset as KiCad's own library save resets it (every child keeping its uuid, embedded files kept), `{ name, text }`, `text` one `(footprint ...)` of at most 8 MiB. A read: nothing changes; open, take, open, take gives the same text. **`fpedit.markSaved { token }`** clears the modified flag once the host has written what it took (`bad_args` "fpedit.markSaved: the token is not the open footprint's" when `token` is not the state's; no undo step).
- **`shutdown`** in an `fpedit` frame never asks KiCad's close question: the host decides Save, Discard or Stay before it.
