### microwave.arm
The values of KiCad's microwave tools given before the press, in a `pcb` frame with a board open (island `v0.2.3-cc25`, on an engine with `kicadMicrowaveArm`, engine run 15; a host gates it on `ev.ready` `caps` listing `microwave`, listed by `pcb` frames only). The host arms, then presses the row's chord with `key.press` (`pcbnew.MicrowaveTool.createGap`, `createStub`, `createStubArc`, `createLine`, `createFunctionShape`): the shape hangs on the pointer with no KiCad window, one click places it as one undo step, and the tool ends after that one placement. The engine holds ONE pending arm: the start of any microwave action consumes it and only a matching shape uses it (arming `stub` then pressing Gap loses the arm and Gap asks KiCad's value). Unarmed, Gap, Stub and Arc stub ask their value through the generic `entry` ask, but Shape opens KiCad's own dialog (it has no ask), so a host always arms before pressing Shape.

The args, read closed with the engine's own bounds: `value` in mm, over 0 and at most 500 (the track length for `line`, the gap or stub size, the arc stub's radius); `angle` 0 to 180 degrees, absent 0; `polygon.points` 2 to 2,048 pairs as a shape file's `$COORD` lines write them (fractions, not mm), `polygon.size` the scale in mm (the file's `XScale` and `YScale`, or what the reader typed), each component nonzero and at most 500, every point times the size within 1,000 mm; `kind` `plain` (KiCad's Normal), `symmetrical` or `mirrored`. `line` places an `mw_inductor` valued `L`. The checks, in order: the args (`bad_args`); the frame (`unsupported` "a board op runs in a pcb frame"); the engine (`not_ready`, `unsupported` naming `kicadMicrowaveArm`); a board open (`not_ready`); a load parked, a popup or a dialog up, or an item hanging off the pointer (`busy`). `busy` too when the engine cannot arm now (an open in flight, a dialog showing); the earlier arm then stands. Errors KiCad raises after the values (a line shorter than its minimum, a shape of null size) stay KiCad's info bar messages and the armed run still ends.
