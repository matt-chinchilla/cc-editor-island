### embedded.get, embedded.set and embedded.extract

The files a design keeps inside its own board or schematic file (KiCad's embedded files: fonts, 3D models, drawing sheets, datasheets and others), for the host's Setup section Embedded files (island `v0.2.3-cc25`, on an engine with `kicadEmbeddedFilesGet`, `kicadEmbeddedFilesSet`, `kicadEmbeddedFileExtract` and `kicadCollabBusy`, engine run 15; a host gates them on `ev.ready` `caps` listing `designEmbedded`, listed by a `sch` and a `pcb` frame). On an older engine the cap is absent and each op answers `unsupported` naming the export (`kicadEmbeddedFilesGet` first). Any other frame answers `unsupported`. Each op works on the document of its frame: the board in a `pcb` frame, the schematic in a `sch` frame.

- `embedded.get` answers the engine's read: `owner` the document's kind, `fontsEmbedded` whether the document keeps its fonts inside, `files` every embedded file (at most 1,024: `name`, `type` KiCad's word, `bytes` its size decompressed, `heldBy` how many footprints or library symbols also carry a file of that name), `fonts` the outline fonts the document draws with and whether each is kept. It is answered during a `sheet.check` or a `board.check`.
- `embedded.set` changes them, with no undo step (KiCad's Setup makes none) and the document marked modified, so the next `project.save` writes the change (after `fonts` with `embed` true, KiCad's writer carries the fonts). `add` writes `bytes` (1 byte to 25 MiB) into one fresh `/tmp/cc-embed/<n>/` and keeps the file under `name` (1 to 255 characters, no slash or backslash, never `.` or `..`, and never `embedded.json` or `.cc-embed-out.json`, the names of the engine's own records, which answer `bad_args`) as `type`, a file of that name replaced; `bad_args` "embedded.set: KiCad refused the file" when the engine refuses it. `remove` takes the named file out, with `alsoHeld` from the footprints or symbols that carry it as well (KiCad's "Delete from footprints as well?"); `not_found` names a file the document does not hold, and nothing is sent then. `fonts` sets whether the document keeps its fonts inside; with `embed` true the fonts it draws with are added now. The answer is the read (as `embedded.get`) once the engine's record is there and the read shows the change; `not_applied` when the engine refuses a remove or a fonts set, its record says so, the change does not show, or the record does not come within 30 s. The folder is removed after every answer.
- `embedded.extract` answers the named file's bytes as the document holds them, decompressed (the engine writes them into one fresh `/tmp/cc-embed-out/<n>/`, removed after the answer; the buffer is transferred). A file named `.cc-embed-out.json`, the extract's own record, is never taken out: `bad_args`. `not_found` names a file the document does not hold, `too_large` names one past 25 MiB, `not_applied` when the engine refuses the extract or its record says it failed (`message` "embedded.extract: " and the engine's word). It is answered during a check.
- The checks, in order, for each: the args (`bad_args`), the frame, the engine (`not_ready`, `unsupported`), a document open (`not_ready`), busy as for a board op in a `pcb` frame and a schematic op in a `sch` frame (and `busy` while the engine cannot read the document's files).
