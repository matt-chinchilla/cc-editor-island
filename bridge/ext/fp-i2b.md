- `ev.fpedit { ask, uuid, isNew }`: in an `fpedit` frame (island `v0.2.3-cc25`, cap `fpeditHeld`), KiCad's footprint editor was about to open one of its windows and opened none; the host shows its own. `ask` is the window's subject: an item's (`pad`, `field`, `text`, `textbox`, `shape`, `dimension`, `zone`, `table`, `barcode`, `image`, `point`, with the item's `uuid`; a table cell asks its table), `pushPad` (Push Pad Properties, the source pad's `uuid`), a new item a drawing tool just placed (`text`, `textbox`, `table`, `barcode` with the new `uuid` and `isNew` true, placed as the window's OK with its defaults would place it: a text reading "Text", KiCad's table, a QR barcode), a new reference picture (`image`, `uuid` "", `isNew` true: nothing placed), or the footprint or the frame with `uuid` "": `footprint` (its properties; E on nothing), `padDefaults`, `padTable`, `enumerate` (Renumber Pads: the numbering does not start; the host answers with `fpedit.enumerate`), `wizard`, `newFootprint`, `rename`, `cleanup` (Cleanup Graphics), `graphics` (Import a drawing). An item stays the one selected; a frame ask changes nothing. Sent once per request, after `ev.ready`, while a footprint is open.

### The footprint editor's asks, pad defaults and numbering

Island `v0.2.3-cc25`, in an `fpedit` frame, on an engine with every fpedit export (engine run 15); a host gates the ops on `ev.ready` `caps` listing `fpedit`, and `ev.fpedit` on `fpeditHeld` (the engine's marker `kicadHostFpEdit` beside every fpedit export: KiCad's footprint editor then asks the island before each of its windows, and the island takes every ask). In every other frame each op answers `unsupported` ("a footprint edits in an fpedit frame"); on an engine without the exports, `unsupported` naming the first missing one. The checks run in this order, each before any effect: the args (`bad_args`), the frame, the engine (`not_ready`, `unsupported`), a load parked or a popup menu or a dialog up (`busy`), then for `fpedit.enumerate` a footprint open (`no_footprint`).

- **`PadDefaults`** is the master pad KiCad gives every new pad (its Default Pad Properties): every key of the `pad` record of `fpedit.items.get` but `kind` and `uuid`, its position 0, 0.
- **`fpedit.padDefaults.get`** answers the master pad, a footprint open or not. Answered during a check (a read).
- **`fpedit.padDefaults.set { set }`**: `set` a non empty partial of a pad's keys, read as `fpedit.items.set` reads a pad's (`bad_args` otherwise). KiCad's pad window rules apply: what it refuses answers `bad_args`, what it resets is reset (a circle squares its size). Applied at once, with no undo step, the footprint not modified; a `number` given also becomes the pad tool's next number. The answer is the master pad read back.
- **`fpedit.enumerate { start, step, prefix }`**: `start` and `step` whole numbers 0 to 999, `prefix` 0 to 64 characters with no control character (KiCad's Renumber Pads window's fields). Starts KiCad's own numbering on the open footprint with no window: the reader clicks or drags across the pads, each taking `prefix` and the next number, and KiCad commits the run as ONE undo step on a double click or a tool change (then `ev.edited`), Esc taking it back. The answer `{}` comes as the numbering starts, before the reader's first press. `bad_args` for a footprint with no pads, `busy` while a pad is taken apart (pad edit mode), `not_applied` when KiCad does not start it.
