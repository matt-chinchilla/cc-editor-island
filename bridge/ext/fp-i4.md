### footprint.forEditor and footprint.push
The board side of the footprint editor, in a `pcb` frame with a board open (island `v0.2.3-cc25`, on an engine with `kicadFootprintForEditor`, `kicadFootprintPushToBoard`, `kicadBoardItemGet` and `kicadCollabBusy`, engine run 15; a host gates both on `caps` listing `footprintEdit`, listed by `pcb` frames only). The checks, in order, before any effect: the args (`bad_args`); the frame (an `fpedit` frame answers `unsupported` "a footprint editor opens footprints, not documents", a `sch` or `symedit` frame `unsupported` "footprints are read in a pcb or an fpedit frame"); the engine (`not_ready`, `unsupported` naming the first missing export); a board open (`not_ready`); a load parked, a popup or a dialog up, or an item hanging off the pointer (`busy`).

- `footprint.forEditor { uuid }` answers the placed footprint exactly as KiCad's Load Footprint from Board copies it (a clone, unlocked, its nets cleared, flipped to the front, angle 0, at the origin) with every child keeping the BOARD's uuid, formatted as a library save writes it (no library nickname, no `(at)` on the footprint, no pad nets, embedded files kept): `{ name, libId, ref, text }`, `text` one `(footprint ...)` of at most 8 MiB, ready for `fpedit.open` with `mode` `placed`. `not_found` (the uuid) when the board places no footprint by that uuid.
- `footprint.push { uuid, text, libId }` is KiCad's Save Footprint to Board of an edited footprint (`SaveFootprintToBoard`'s update body through `ExchangeFootprint`): a child whose uuid the placed footprint holds keeps it, any other takes a fresh one; the pads take the placed part's nets by name; the part keeps its position, angle, side and its own uuid; ONE commit "Update footprint": one undo step and an `ev.edited`. `text` is ONE `(footprint ...)` of at most 8 MiB. `libId` `""` keeps the footprint the part names; `lib:name` (both halves) sets it in the same commit, so the part names the design's own copy. Nothing is restyled (a fresh footprint editor's settings apply no board defaults to footprint fields, texts, shapes, dimensions or barcodes). The answer is `{ uuid }` once the apply queue is empty and the part reads back through `board.item.get`'s read (with a `libId`, naming it); the host reads the part's record with `board.item.get`. `not_found` (the uuid) when the board places no footprint by that uuid; `bad_args` "footprint.push: the text holds no footprint KiCad reads" when the engine refuses the text (nothing queued, no undo step); `not_applied` past about 5 s. The host's next `project.save` writes the change.

### footprint.convert
Reads a footprint file of another tool, or of an older KiCad, with KiCad's own readers, and answers its footprints as text (island `v0.2.3-cc25`, on an engine with `kicadFootprintConvert`, engine run 15; a host gates it on `caps` listing `footprintConvert`, listed by `pcb` and `fpedit` frames). The args are exactly `{ name, bytes }`: the file's name (1 to 255 bytes of UTF-8, no slash, backslash or NUL, never `.` or `..`) and its bytes (a `Uint8Array` of 1 byte to 25 MiB). The frame writes the file under a fresh `/tmp/cc-import/<n>/`, outside the project folder, and removes the folder after the read. A file KiCad's `PCB_IO_MGR` takes as a set of footprints is read whole (each footprint KiCad's reader enumerates, then loads); any other file is read as ONE footprint by the first reader whose `CanReadFootprint` takes it (KiCad's Import Footprint). Each footprint is reset as a library save resets it (angle 0, on the front) and formatted as `fpedit.take` formats one. The answer is `{ format, footprints: [{ name, text }] }`, `format` KiCad's own name of the reader. `unreadable` when no reader takes the file, the reader refuses it or reads nothing (`message` KiCad's sentence, or "KiCad read no footprint from this file"), `too_large` past 2,000 footprints or 8 MiB of their text. A `sch` or `symedit` frame answers `unsupported`. The checks: the args, the frame, the engine (`not_ready`, `unsupported`), busy while a load is parked or a popup or a dialog is up; it needs no document open.

The readers of KiCad 10 the engine registers, by `format` and the files they take (the run 15 probe owes the measured list, gate 0 item 3): `KiCad` (`.kicad_mod`), `Legacy` (KiCad 5 `.mod`, `.emp`), `Eagle` (`.lbr`), `gEDA / Lepton EDA` (`.fp`), `Altium Designer` (`.PcbLib`, `.IntLib`), `EasyEDA / JLCEDA Std` (`.json`), `EasyEDA / JLCEDA Pro` (`.elibz`, `.epro`) and `PADS` (`.asc`). The fixtures `tests/fixtures/footprint-convert/legacy.mod` (one KiCad 5 footprint, `LEGACY_R0805`) and `package.lbr` (one Eagle package, `EAGLE_R0603`) read as `Legacy` and `Eagle`, one footprint each, in a `pcb` and an `fpedit` frame (`tests/e2e/footprint-edit.spec.ts`, engine run 15).
