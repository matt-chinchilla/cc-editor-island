### The drawing sheet editor: a ds frame and the dsedit ops

Island `v0.2.3-cc25`, on an engine with the dsedit exports (engine run 15); a host gates every op on `ev.ready` `caps` listing `dsedit`.

- **The frame.** `?frame=ds` boots KiCad's own drawing sheet editor (`PL_EDITOR_FRAME`, the tool `pl_editor` in the merged editor image), canvas only. A `ds` frame holds no document: every op that ships answers `unsupported` ("a drawing sheet editor opens drawing sheets, not documents") but `key.press`, `keys.claim`, `chrome.show`, `view.fit`, `select` and `shutdown`. In every other frame each `dsedit` op answers `unsupported` ("a drawing sheet edits in a ds frame"). A `ds` frame's `ev.ready` lists only `dsedit` (every export below present), `heldKeys`, `hostKeys` and the engine's export names; no other frame lists `dsedit`. `ev.edited` in a `ds` frame carries the sheet's undo depth while a sheet is open (an open starts the count again and sends none); `ev.selected` carries the sheet's selected items (`fpPaths` `[]`), while a sheet is open.
- **The checks**, in order, every one before any effect: the frame's kind (`unsupported`); the args (`bad_args`); the engine (`not_ready` before it is up; `unsupported` naming the first missing export of `kicadDsEditOpen`, `kicadDsEditState`, `kicadDsEditTake`, `kicadDsEditMarkSaved`, `kicadDsEditItemsGet`, `kicadDsEditItemsSet`, `kicadDsEditItemsAdd`, `kicadDsEditItemsRemove`, `kicadDsEditDefaultsGet`, `kicadDsEditDefaultsSet`, `kicadDsEditPreviewGet`, `kicadDsEditPreviewSet`, `kicadDsEditShow`, `kicadDsEditSelection`, `kicadDsEditSelect`, `kicadDsEditAppend`, `kicadDsEditArmImage`, `kicadCollabBusy`); a load parked, a popup menu or a dialog up (`busy`, nothing changed); then `no_sheet` for every op but `dsedit.open` and `dsedit.state` while no sheet is open. A change answers once the engine's apply queue is empty and the state shows it, else `not_applied` after about 5 s.
  - `DsEditState`: exactly `{ token, open, name, modified, depth (the undo depth), page (1: page 1, 2: the other pages), values (true: the title block filled in; false: its names as typed), items (the sheet's item count) }`. `token` is the island's own for the last open (1 to 64 printable characters, `""` before any), which `dsedit.markSaved` names; `name` is the sheet's path in the design (`""` before any open).
- **`dsedit.open`** opens a drawing sheet: `source` `text` (then `text`, a `kicad_wks` or a legacy `page_layout` document, which KiCad's own parser reads into a scratch model first: `unreadable` with KiCad's line and nothing changed when it cannot), `default` (KiCad's built in sheet, the one every new design draws) or `empty` (KiCad's own empty sheet, which keeps one zero length line); `name` 1 to 1,024 characters with no control character (the frame's title only: nothing is ever written there); `discard` a boolean (`held_edits` when the open sheet holds changes and it is false). Past 8 MiB of text: `too_large`. The undo list starts empty, the sheet unmodified, on page 1 with its values shown. The answer is the state once the engine shows the open, with a fresh token.
- **`dsedit.state`** answers the state, a sheet open or not. **`dsedit.take`** answers the open sheet as a `kicad_wks` document by KiCad's own formatter, `{ name, text }`, with no `(uuid ...)` token (kicad-cli 10.0 refuses one): item uuids hold for the life of one open, so a take opened again gives the same items, order and properties under fresh uuids. A read: nothing changes. **`dsedit.markSaved { token }`** clears the modified flag once the host has written what it took (`bad_args` when `token` is not the state's; no undo step).
- **`dsedit.show { page, values }`** shows page 1 or the other pages, and the title block's values or its names, then redraws: no undo step, not a modification. The answer is the state once it shows both.
- **Held.** In a `ds` frame, under `dsedit`, while a sheet is open, these actions send `ev.held { action }` and open no window of KiCad's: `common.Control.new`, `common.Control.open`, `common.Control.save`, `common.Control.saveAs`, `common.Control.print`, `common.Control.plot`, `common.Control.quit`, `plEditor.EditorControl.ShowInspector`, `plEditor.EditorControl.PreviewSettings`, `plEditor.InteractiveEdit.appendWorksheet`, `common.SuiteControl.openPreferences` and `common.SuiteControl.listHotKeys` (the last two: nothing of the host's replaces them).
- **`shutdown`** in a `ds` frame never asks KiCad's close question: the host decides Save, Discard or Stay before it.
