### board.session
Reads a router's Specctra session (`.ses`) into the open board with KiCad's own session reader, in a `pcb` frame with a board open (island `v0.2.3-cc25`, on an engine with `kicadImportSession` and `kicadCollabBusy`, engine run 15; a host gates it on `ev.ready` `caps` listing `session`, listed by `pcb` frames only). The args are exactly `{ name, bytes, preview }`: the file's name (ending `.ses` in any case, 1 to 255 bytes of UTF-8, no slash, backslash or control character), its bytes (a `Uint8Array` of 1 byte to 25 MiB) and a boolean. The checks, in order, before any effect: the args (`bad_args`); the frame (`unsupported` "a router session is read in a pcb frame"); the engine (`not_ready`, `unsupported` naming the first missing export); a board open (`not_ready`); a load parked, a popup or a dialog up, or an item hanging off the pointer (`busy`). During a `board.check`, a `sheet.check` or an import it answers `busy`.

The frame writes the bytes under a fresh `/tmp/cc-stage/<n>/` (never the project folder: the session does not join the design through the frame; the host keeps the reader's file under `imports/` itself), queues the run with a fresh `/tmp/cc-session/<n>/` for its records, waits for the apply queue to empty and the run's record, and removes both folders whatever the answer.

- `preview: true` loads the session and counts it against the board with nothing changed: `tracks` (each track segment and arc the session routes), `vias` (each via it places), `nets` (the nets it names) and `missingNets` (the names the board lacks, at most 256), `undoCleared` false, `depth` the undo depth as it stands.
- `preview: false` reads it as KiCad's Import Specctra Session does (the unlocked tracks and vias and every marker removed, each placed footprint moved as the session places it, the routes added, the ratsnest rebuilt) as ONE commit "Import Specctra Session": one undo step, and an `ev.edited` once the depth moved. The answer adds `removed` and `added` (`{ tracks, vias }`, locked copper counted in neither) and `depth` the undo depth after; `undoCleared` is true only on an engine that clears the undo history as KiCad's own menu path does (engine run 15 never does).

`session_invalid` when KiCad cannot read the session (the board as it was); `not_applied` when the engine refused the run or no record came within about 60 s; `island_error` for a record of another shape. KiCad's own File > Import > Specctra Session (`pcbnew.EditorControl.importSpecctraSession`) is held in a `pcb` frame under the cap `session`: it sends `ev.held { action }` and opens no window. The fixtures `tests/fixtures/st-session-card/business-card.ses` (5 tracks, 1 via, 3 nets, missing `/NFC_ANT`) and `corrupt.ses` (truncated) on the business card board (`tests/e2e/st/st-ses-i.spec.ts`, engine run 15).
